# 🏥 Healthcare Data Analysis Project

## 📌 Project Overview

This project focuses on analyzing healthcare data to identify meaningful patterns and insights related to **patient demographics, medical conditions, hospital admissions, billing, insurance providers, medications, and test results**.

The analysis was performed on a dataset containing **10,000 patient records** and was designed to answer a series of business and healthcare-related analytical questions.

## 🎯 Objectives

* Analyze patient demographics and medical conditions.
* Understand the distribution of patients across different age groups and genders.
* Identify relationships between medical conditions and blood groups.
* Analyze patient admissions and discharge patterns.
* Compare billing amounts across medical conditions and insurance providers.
* Analyze medications and test results.
* Identify trends that can help healthcare organizations make data-driven decisions.

## 📊 Dataset

The dataset contains **10,000 patient records** with information such as:

* Patient Name
* Age
* Gender
* Blood Type
* Medical Condition
* Date of Admission
* Doctor
* Hospital
* Insurance Provider
* Billing Amount
* Room Number
* Admission Type
* Discharge Date
* Medication
* Test Results
* Age Group
